This project was developed during the course Intelligence Artificielle et Jeux to study the assignment of students to Master's tracks with limited capacities. Both student-proposing and track-proposing variants of the Gale-Shapley algorithm were implemented in Python, along with a function to detect unstable pairs. Execution times and iteration counts were then benchmarked on randomly generated preferences for up to 2,000 students to compare empirical performance against theoretical complexity. Finally, Integer Linear Programming (ILP) models were solved with GLPK to maximize Borda satisfaction scores under top-$k$ choice constraints, illustrating the trade-off between fairness and stability.
