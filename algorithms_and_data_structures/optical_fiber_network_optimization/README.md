# Optical Fiber Network Reconstruction & Optimization

This project was developed during the Data Structures course (LU2IN006) to reconstruct and reorganize a municipal optical fiber network in C. First, the global network topology is rebuilt from individual operator fiber chains and exported as interactive SVG visualizations. To optimize spatial node lookups during reconstruction, three data structures were implemented from scratch and benchmarked across large randomly generated networks: a singly linked list, a hash table with separate chaining, and a spatial quadtree. Finally, the network is modeled as an adjacency-list graph where Breadth-First Search (BFS) computes the shortest path for each client pair and verifies that cable capacity constraints are respected across all links.
