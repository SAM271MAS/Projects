# Cryptography Labs

This repository contains Python implementations of classical and modern cryptographic schemes, number-theoretic primitives, and cryptanalysis techniques developed as part of an introductory cryptology course (LU3IN024) for the year 2024/2025.

## Repository Structure

* `monoalphabetic-ciphers/`** — Caesar and monoalphabetic substitution ciphers, letter frequency analysis, and automated hill-climbing cryptanalysis.
* `vigenere-cryptanalysis/`** — Vigenère cipher implementation and statistical cryptanalysis using the Index of Coincidence, Mutual Index of Coincidence, and Pearson correlation.
* `arithmetic-and-dlp/`** — Modular arithmetic primitives, cyclic group operations in $(\mathbb{Z}/p\mathbb{Z})^\times$, safe prime generation, and Shanks' Baby-Step Giant-Step algorithm for the Discrete Logarithm Problem.
* `rsa-and-wiener-attack/`** — RSA encryption/decryption, Chinese Remainder Theorem (CRT) optimization, and Wiener's continued-fraction attack on small private exponents.
* `elliptic-curve-cryptography/`** — Elliptic curve arithmetic over finite fields $\mathbb{F}_p$, point counting, scalar multiplication, and Elliptic Curve Diffie-Hellman (ECDH) key exchange.
